# Integrations

## On-device engines (ASR→MT→TTS sequential — no network)
- Pipeline: **Push-to-talk (AudioRecord 16 kHz) → Silero VAD/SherpaAsr (whisper-tiny fixture; IndicConformer candidate) → text normalize (`IndicProcessorPort`) → IndicTrans2 ONNX INT8 MT (`hin_Deva→sat_Olck`) → Ol Chiki validate (U+1C50–U+1C7F) → Santali VITS TTS (sherpa `OfflineTts`, 22.05 kHz mono) → AudioTrack**. Orchestrated by `android/ml/orchestrator/Orchestrator.kt` + `EngineProvider.real()` + `EngineContracts`; **strictly sequential** (`ReentrantLock` in MT adapter, singleton CT2 translator, `numThreads=1`, `WITH_OPENMP` tuned for 2 GB) — never parallel per AGENTS.md RAM limit.
- Latency budget: ASR ≤1s / MT ≤0.5s / TTS ≤1s, total <3s (`LatencyTracker` in `:core` + `:ml`, `ml/pipeline/latency.py`, `AudioPipelineTest`, demo diagnostics screen).
- Zero-network enforcement: **no `INTERNET` permission** in manifest; `grep` + `network_request_audit` in `ml/benchmarks`; HF downloads are build-time only (`ml/export_venv`, `indictrans2-onnx-export`). `PackInstaller` uses SAF `ContentResolver` only — no `HttpURLConnection`.

## Integration risks / version drift
- **Size budget overrun**: MT 359 MB (vs 180 MB slice) + TTS 110 MB (vs 80 MB) + tokenizers 48 MB → ~500 MB total under pressure; mitigation per `docs/phases/P1-size-variance.md` (INT8+zip, Q4F16, vocab prune, pack-split).
- **ORT duplication**: sherpa AAR's `libonnxruntime.so` vs gradle `onnxruntime-android` — currently resolved by `pickFirsts`; catalog 1.24.3 vs device 1.18.0 vs export ORT 1.27 — pin and align before release.
- **sherpa API variance**: Python `OfflineTts*` surface varies by version (code already try/excepts); AAR 1.13.0 vs Python 1.13.8 cross-check — re-verify on bump; TTS generation flag (`tts v2` 38-token vs v1 55-token shim + `isShim` gate) must bump `assetVersion` on any voice swap or stale filesDir serves old model.
- **CT2 native fragility**: FetchContent at build time = network-at-build + NDK dependency; `libctranslate2` preload order is OEM-sensitive (`Ct2Jni` explicit load chain); host x86_64 fallback differs from arm64-v8a runtime — CI must build with NDK.
- **ASR production gap**: whisper-tiny fixture is NOT final Hindi/Mundari ASR; IndicConformer/Vosk/whisper.cpp benchmark on 2 GB device still open; TTS-native-consent gap (§9) blocks release-grade native voice.
- **License contamination**: Piper/espeak-ng are GPL-3.0 — keep build/dev-only (APK has zero GPL); Mundari BY-NC-SA-FS data triggers GPL-or-later incorporator clause + NC bar — keep quarantined; model license ≠ repo license — verify per artifact.

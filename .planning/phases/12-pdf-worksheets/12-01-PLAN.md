chapters (`/cz/Vachak/1/` → Grade 1, `/cz/Vachak/3/` → Grade 3: JSON + webp,

distinct PDFs). Output: converter + converted chapters + pool + v0.3.0 pack +

<threat_model>
STRIDE: Tampering (authored inputs hashed at convert time into mapping.json; pool files pinned by sha256 in mapping + pack manifest; builder fails loud on hash/size mismatch, never silently substitutes; converter asserts no emitted status == APPROVED), Denial (pool cap 25 MB enforced in-script; filling-and-lifting missing-JSON path is honest-empty, never a build break), Information Disclosure (none — local textbook/authored files only).
ASVS L1: Build-time Python only; no runtime input handling added. Path handling: pool refs and image_refs are relative, resolved against pack/chapter roots — no absolute paths, no `..` segments accepted (asserted in tests).
Mitigations: determinism (sorted traversal => identical bytes); missing authored JSON => reserved honest-empty slot, never invented content; DRAFT flows verbatim; legacy extra chapter dirs stay in the pack file untouched (only the pack_summary listing is scoped to 6/grade).
</threat_model>
